# Getting Help

**Bugs and feature requests.** Open an issue at
[github.com/spyderps05/PrimeCrestConstMgmt/issues](https://github.com/spyderps05/PrimeCrestConstMgmt/issues).
Include the version you run and the steps that lead to the problem.

**Questions, onboarding and support.** Write to support@primecrest.pk. Documentation is at
[docs.primecrest.pk](https://docs.primecrest.pk).

Security vulnerabilities do not go in public issues. See [SECURITY.md](SECURITY.md).
